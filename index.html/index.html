Peter Lundy | Environmental Mapping & GIS Portfolio

About Me

I am an environmental studies student developing practical skills in Geographic Information Systems (GIS), web mapping, and spatial analysis. My work focuses on understanding how environmental patterns, infrastructure, and human activity interact across space.

What This Portfolio Shows

  • Interactive web maps built with Leaflet and GitHub Pages
  • Use of spatial data including GeoJSON and external datasets
  • Visualization techniques such as proportional symbols and choropleth mapping
  • User interaction through map clicks, popups, and real-time feedback

Course Progression

  • Started with basic map setup, markers, and popups
  • Moved into scaled symbols and data-driven visualization
  • Built interactive mapping tools and user-based inputs
  • Applied GIS concepts to environmental and spatial patterns
